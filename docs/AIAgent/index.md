# AI Agent 技术专题

面向 Java 工程师的 AI Agent 开发学习路线，从 LLM 基础到完整 RAG 系统落地。

## 学习路线

| 顺序 | 主题 | 核心内容 |
|------|------|----------|
| 1 | LLM 基础与 Java 集成 | Token、模型选型、API 调用、流式响应 |
| 2 | Agent 设计模式 | ReAct、CoT 思维链、Function Calling、记忆机制 |
| 3 | RAG 检索增强生成 | 文档处理、Embedding、向量数据库、检索策略 |
| 4 | Prompt 工程进阶 | 设计原则、Few-shot、Structured Output、注入防护 |
| 5 | LangChain4j 实战 | AiServices、Tool Calling、RAG 集成、Spring Boot 整合 |
