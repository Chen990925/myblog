# 微服务治理主题总览（对话总结）

> 本文档总结"简历面试准备——微服务治理"对话的全部产出，作为入口和索引。
> 与 JVM、并发编程、Redis、Oracle、RocketMQ 主题同属面试准备系列，假设环境 **8 核 8 线程 / 500GB 硬盘 / 32GB 内存**。

## 一、对话目标与约定

- 目标：基于本项目（cloudsrv，银行间/交易所指令交易 OMS 系统）准备简历与面试内容
- 流程：按主题逐块准备（JVM → 并发 → Redis → Oracle → RocketMQ → 微服务治理 → …），产出写入 `笔记/`；"结束并总结"时汇总
- 当前阶段：微服务治理板块已完整（架构/注册配置/网关/Feign/容错/排查 + 速记卡）

## 二、本主题已覆盖内容（按对话顺序）

1. **项目治理能力盘点**：Nacos 注册+配置、Gateway 双路由、RequestFilter、109 个 Feign 客户端、**无 Sentinel（校准项）**（→ `微服务0-准备点清单.md` §0）
2. **架构与服务拆分/通信方式**：10 个服务、拆分原则、Feign 同步 vs MQ 异步的选择逻辑（→ `微服务1-架构与服务拆分.md`）
3. **Nacos 注册发现 + 配置中心**：心跳/剔除/推拉结合、Nacos vs Eureka vs ZK、namespace/group 多环境隔离、@RefreshScope（→ `微服务2-Nacos注册发现与配置中心.md`）
4. **API 网关**：Route/Predicate/Filter、**双路由设计**（自动路由 + oms.access 功能号路由表）、RequestFilter 真实 IP、响应式 vs Zuul（→ `微服务3-API网关.md`）
5. **Feign + 负载均衡**：动态代理原理、contextId、**readTimeout=600s 问题**、重试配幂等、LoadBalancer（→ `微服务4-Feign与负载均衡.md`）
6. **容错治理**：熔断/降级/隔离、Sentinel 状态机、**项目未实现的诚实校准 + 改进方案**、限流算法（→ `微服务5-容错治理.md`）
7. **生产问题排查**：服务摘除、超时雪崩、配置变更故障、工具链短板（→ `微服务6-生产问题排查.md`）

- **首次准备**（约 2~3 天）：总览 → 准备点清单 → 架构 → Nacos → 网关 → Feign → 容错 → 排查
- **考前冲刺**：`微服务速记卡.md` + 主打案例（Feign 超时雪崩 + 治理改进方案）练 STAR
- **主打案例**：① Feign readTimeout 600s 的雪崩分析（呼应 JVM 案例 4）② 熔断降级缺失的分析与改进方案（诚实校准 + 有方案）

## 五、简历落点（可直接引用）

> 参与微服务治理体系建设：基于 Nacos 实现服务注册发现与配置中心（namespace 隔离环境、group 隔离业务线，支持 Nacos/ZK 双注册中心）；主导 API 网关双路由设计（discovery 自动路由 + 功能号路由表对接外部 IR），实现网关全局过滤器（请求日志 + 多级代理真实 IP 解析）；维护 109 个 Feign 服务间调用客户端（contextId 多客户端隔离 + 统一响应包装）。

> 分析并推动容错能力建设：定位 Feign readTimeout 配置过长（600s）导致外部依赖变慢时线程池耗尽的雪崩风险（生产已现 CFETS 变慢连锁影响），提出"超时分级收紧 + Sentinel 熔断 + 信号量隔离 + 回报链路 MQ 异步化"的改进方案并落地异步化部分。
