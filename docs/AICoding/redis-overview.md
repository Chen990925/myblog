# Redis 缓存主题总览（对话总结）

- 当前阶段：Redis 缓存板块已完整（数据结构与三大问题 / 一致性 / 分布式锁 / 持久化高可用 / 性能调优 + 速记卡）

## 二、本主题已覆盖内容（按对话顺序）

1. **项目缓存使用全景**：成交回报去重锁、接口幂等、报价状态同步、系统参数缓存、分布式锁、数据增量标记、登录会话七大场景（→ `Redis0-准备点清单.md` §0）
2. **推荐学习顺序**：数据结构+三大问题 → 一致性 → 分布式锁 → 持久化高可用 → 性能调优 → 案例串讲
3. **数据结构 + 三大问题**：五种结构、单线程模型、穿透/击穿/雪崩（→ `Redis1-数据结构与缓存三大问题.md`）
4. **缓存一致性**：Cache Aside、延迟双删、Canal、项目 delete+重建的窗口优化（→ `Redis2-缓存一致性.md`）
5. **Redis 分布式锁**：三要素、项目 RedisUtil 锁误删/无续期/自旋空转三问题、Redisson 看门狗、RedLock/CAP（→ `Redis3-分布式锁.md`）

## 五、简历落点（可直接引用）

> 深入实践 Redis 缓存与分布式锁：成交回报处理按订单主键加 Redis 分布式锁防止并发重复处理，配合状态乐观锁双层防御；主导系统参数 Redis 缓存建设（Hash 全量预热 + 变更刷新），优化删建窗口与大 Key 阻塞问题；应用缓存空值/布隆过滤方案应对缓存穿透，基于缓存一致性策略（延迟双删/原子切换）保障最终一致。

> 发现并分析 RedisUtil 分布式锁的释放校验缺陷（未校验持有者导致锁误删、互斥失效），给出 Lua 比对删除 + 看门狗续期修复方案，保障多实例下成交处理的互斥正确性。
