# RocketMQ 主题总览（对话总结）

> 本文档总结"简历面试准备——RocketMQ"对话的全部产出，作为入口和索引。
> 与 JVM、并发编程、Redis、Oracle 主题同属面试准备系列，假设环境 **8 核 8 线程 / 500GB 硬盘 / 32GB 内存**。

## 一、对话目标与约定

- 目标：基于本项目（cloudsrv，银行间/交易所指令交易 OMS 系统）准备简历与面试内容
- 流程：按主题逐块准备（JVM → 并发 → Redis → Oracle → RocketMQ → …），产出持续写入 `笔记/`；"结束并总结"时汇总
- 当前阶段：RocketMQ 板块已完整（基础 / 生产端可靠发送 / Broker 存储 / 消费端 ACK 三层兜底 / 生产排查 + 速记卡），覆盖用户指定四要点（生产端确认、Broker 持久化、消费端手动 ACK 三层兜底、生产问题排查）

## 二、本主题已覆盖内容（按对话顺序）

1. **项目 MQ 使用全景**：生产端全 asyncSend+SendCallback、oms-trade-00xx 成对 topic、消费端 @RocketMQMessageListener 自动 ACK、AOP tag、跨服务链路（→ `MQ0-准备点清单.md` §0）
2. **MQ 基础与项目用途**：异步/削峰/解耦三大价值与代价、核心概念、选型（RocketMQ vs Kafka）、topic 体系设计（→ `MQ1-MQ基础与项目用途.md`）
3. **生产端可靠发送（生产端确认）**：三种发送方式、SendResult 四状态、重试、本地补偿表、事务消息（→ `MQ2-生产端可靠发送.md`）
4. **Broker 存储与持久化（Broker 持久化）**：commitlog/consumequeue/index、同步/异步刷盘、主从复制、可靠性矩阵（→ `MQ3-Broker存储与持久化.md`）
5. **消费端手动 ACK 三层兜底（消费 ACK）**：自动 vs 手动、ACK 重试/DLQ/业务幂等、顺序消费（→ `MQ4-消费端ACK三层兜底.md`）
6. **生产问题排查（排查）**：丢/重/乱/积四类、堆积/重复/丢失/乱序/延迟、mqadmin 工具与 lag 告警（→ `MQ5-生产问题排查.md`）

## 五、简历落点（可直接引用）

> 深入实践 RocketMQ 交易链路异步化：主导下单/撤单/回报链路的 MQ 解耦与削峰设计（REQ/PUSH 成对 topic + Tag 二级过滤），生产端 asyncSend 异步发送不阻塞主链路；分析并改进生产端发送补偿缺失问题（onException 仅记日志 → 本地消息表/事务消息兜底）；消费端按 ACK 重试 + 死信队列 + 业务幂等三层兜底治理（成交处理 Redis 锁 + 乐观锁双层幂等），解决交易回报链路消息堆积问题（慢 SQL 根因 + lag 告警体系）。
